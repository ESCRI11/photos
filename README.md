# Xavier Escribà Montagut — Galeria de fotos

Personal photo gallery. Zero npm dependencies — plain HTML, CSS, and vanilla JS generated by a single Node.js build script.

## Commands

```bash
make build          # Generate docs/ from source
make preview        # Build and serve locally at http://localhost:8000/photos/
make process-photos # Process new photos from to_proces/
make clean          # Delete docs/
```

## Adding photos

1. Drop JPG files into `to_proces/`
2. Run `make process-photos` — you'll be prompted for location and collection
3. Run `make build` to regenerate the site

The script automatically extracts EXIF metadata, assigns grid spans, and updates `public/photos.json` and `public/collections.json`.

## Project structure

```
photos/
├── generate.js             # Build script (Node built-ins only, no npm install needed)
├── src/
│   ├── styles.css          # Plain CSS
│   ├── app.js              # Vanilla JS — lightbox + navigation
│   └── i18n.js             # Translations — language switcher + URL sync
├── public/
│   ├── photos.json         # Photo metadata
│   ├── collections.json    # Album definitions (with multilingual titles/descriptions)
│   └── *.jpg               # Photo files
├── docs/                   # Generated output (GitHub Pages source)
└── process-photos-auto.sh  # Photo processing script
```

## Translations

The site supports **Català (CAT)**, **English (EN)** and **Italiano (IT)**, switchable from the nav bar. The preference is saved in `localStorage`.

### Sharing a link in a specific language

Every page URL includes a `?lang=` parameter that reflects the active language:

```
/photos/collections/solothurn-trip/?lang=it
```

Send that URL and the recipient will see the page in Italian regardless of their own saved preference. To get a shareable link: switch to the desired language, then copy the URL from the browser.

### Adding or editing translations

UI strings live in `src/i18n.js` under the `dict` object.

Album titles and descriptions are in `public/collections.json` — each `title` and `description` field is an object with `ca`, `en`, and `it` keys:

```json
{
  "id": "landscapes",
  "title":       { "ca": "Paisatges", "en": "Landscapes", "it": "Paesaggi" },
  "description": { "ca": "La bellesa natural en monocrom", "en": "Natural beauty in monochrome", "it": "La bellezza naturale in monocromo" },
  "coverImage":  "nature-landscape-black-and-white.jpg"
}
```

After editing either file, run `make build` to regenerate.

## GitHub Pages deployment

1. Run `make build`
2. Commit and push the `docs/` directory
3. In repo Settings → Pages, set source to the `docs/` folder on `main`
